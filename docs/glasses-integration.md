# 显示眼镜接入

本文描述本仓库的输入与显示实现，不分发厂商开发文档存档、内部项目路径或设备标识。

## 显示与输入

主应用按 480×380 横屏内容区域适配。其他分辨率、密度和固件需自行验证；不要将某次测试的密度覆盖值视为所有设备的默认值。黑色背景适用于光学透视显示，但不能阻挡环境光。

`GlassesInputManager` 统一分发 KeyEvent 与系统广播。当前触摸板前滑由 DPAD_RIGHT → DPAD_DOWN 序列识别，后滑由 DPAD_LEFT → DPAD_UP 识别；序列间隔上限为 500ms。单击使用 ENTER，双击使用 BACK，长按兼容 PROG_BLUE 与设备广播。具体交互见根目录 README。

收到佩戴或镜腿状态为 `"0"` 的事件时暂停播放。设备事件名称与额外参数定义在 `GlassesInputManager.Action` 和 `Extra`；新设备应修改对应适配，不要将协议字符串替换为脱敏占位符后用于实机运行。

有序广播按需消费，避免同时触发系统动作。部分固件限制 shell 发送设备广播，ADB KeyEvent 模拟不能替代真实佩戴、折叠与触摸板验证。

## 防抖与生命周期

3DoF 需要 API 29+、可用的姿态传感器和图形能力；不增加相机权限。模式、预测上限、时钟处理与功能边界见 [3DoF 设计](3dof-xr-design.md)。

开启时将 WebView 内容录制到 RenderNode / HardwareRenderer，经 SurfaceTexture 交由独立 GL 线程重投影。关闭时恢复普通 WebView 视频合成。后台完整停止生产者、GL 与 IMU，前台按用户偏好与播放状态重建。画质开关与防抖开关、三种模式分别保存。

性能、画质与光学效果需要分开评价。调试时注明是否开启屏幕镜像、供电方式、视频源与环境光；日志和截图无法证明光学延迟或长期温升。已有短时数据见 [性能验证记录](3dof-performance.md)。

## 设备协议名称

主应用源码保留设备广播标识，以维持兼容性。它们不是凭据或内部地址，修改时需保持与设备系统事件一致。
